# Contributing Guidelines

Thank you for your interest in contributing to this repository!

## How to Contribute

1. **Fork or Branch**: Create a feature branch for your changes (`git checkout -b feature/your-feature-name`).
2. **Commit Changes**: Make sure your commits are clear, descriptive, and atomic.
3. **Security Standards**: Ensure no sensitive data, credentials, API keys, or private tokens are committed.
4. **Pull Request**: Open a Pull Request targeting the `main` branch with a clear description of the modifications.

## Development & Code Quality
- Ensure all manifests, configurations, and code pass linting and security validations.
- Document any new architecture, variables, or policy updates in `docs/` or the root `README.md`.
